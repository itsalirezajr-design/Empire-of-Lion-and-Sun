# Strike Zone — شوتر اول‌شخص تاکتیکی

پروژه‌ی شوتر اول‌شخص تاکتیکی موبایل با Godot 4.4.

## مرحله ۱ — پایه‌ی قابل‌بازی
- حرکت اول‌شخص، دویدن و پرش
- کنترل دوربین با ماوس و لمس چندگانه
- جوی‌استیک مجازی نامرئی در نیمه‌ی چپ صفحه برای حرکت
- نگاه با کشیدن انگشت در نیمه‌ی راست صفحه
- دکمه‌های لمسی شلیک پیوسته، بارگذاری مجدد، پرش و دویدن
- میدان تمرینی سه‌بعدی، موانع دارای برخورد و هدف‌های قابل‌اصابت
- شلیک hitscan، خشاب ۳۰ تایی، ۹۰ فشنگ ذخیره و امتیازدهی
- تنظیمات اولیه‌ی افقی اندروید و فیزیک ۶۰ هرتزی

## کنترل‌ها
**موبایل:** نیمه‌ی چپ صفحه برای حرکت، نیمه‌ی راست برای چرخاندن دوربین؛ دکمه‌های سمت راست برای شلیک، بارگذاری، پرش و دویدن.

**دسکتاپ:** WASD حرکت، ماوس نشانه‌گیری، کلیک چپ شلیک، R بارگذاری، Shift دویدن، Space پرش و Esc آزاد/قفل کردن نشانگر.

## ساخت APK
Workflow در مسیر `.github/workflows/android-apk.yml` با GitHub Actions خروجی آزمایشی ARM64 می‌سازد. خروجی فقط پس از اجرای موفق workflow در بخش Actions به‌عنوان artifact قابل دریافت است.

## وضعیت اعتبارسنجی
کد و تنظیمات در مخزن ثبت شده‌اند؛ با این حال تا زمان اجرای موفق Godot export و نصب و تست روی دستگاه واقعی، سازگاری نهایی، عملکرد لمسی و FPS تأییدشده محسوب نمی‌شوند. مدل‌ها و سلاح فعلی پروتوتایپ ساده‌اند و گرافیک نهایی نیستند.
