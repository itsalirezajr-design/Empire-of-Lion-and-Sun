# Strike Zone — شوتر اول‌شخص تاکتیکی

این مخزن پایه‌ی یک بازی شوتر اول‌شخص تاکتیکی برای موبایل است.

## وضعیت فعلی مرحله ۱
- ساختار اولیه‌ی پروژه در Godot 4.4
- حرکت اول‌شخص با WASD، دویدن و پرش
- چرخش دوربین با ماوس و محدودیت زاویه‌ی عمودی
- میدان تمرینی سه‌بعدی با موانع دارای برخورد
- شلیک hitscan، خشاب ۳۰ تایی، مهمات ذخیره و بارگذاری مجدد
- هدف‌های تمرینی، امتیاز و رابط کاربری اولیه
- تنظیم اولیه‌ی حالت افقی و نرخ فیزیک ۶۰ هرتز برای آماده‌سازی اندروید

## کنترل‌های فعلی دسکتاپ
- W/A/S/D: حرکت
- Mouse: نشانه‌گیری
- Left Click: گرفتن نشانگر ماوس / شلیک
- R: تعویض خشاب
- Shift: دویدن
- Space: پرش
- Esc: آزاد یا قفل کردن نشانگر ماوس

## اجرا
پروژه را با Godot 4.4 یا جدیدتر باز کنید و صحنه‌ی اصلی را اجرا کنید.

## محدودیت‌های فعلی
این نسخه هنوز روی Godot اجرا و اعتبارسنجی نشده است. کنترل لمسی، مدل‌های حرفه‌ای، انیمیشن سلاح، هوش مصنوعی، چندنفره و APK نهایی هنوز ساخته نشده‌اند. تنظیمات اندروید به معنی آماده بودن خروجی نهایی نیست.
