- [x] میدان نبرد ایزومتریک بزرگ با رودخانه و جاده
- [x] انتخاب تکی و گروهی و دوربین چندلمسی پایه
- [x] حرکت گروهی با آرایش ساده و فاصله‌گذاری اولیه
- [x] پیاده‌نظام، تانک و نفربر با شکل‌های متمایز
- [x] مبارزه، جان واحدها و شرط برد و باخت

- [x] HUD موبایل اولیه
- [x] مسیر‌یابی شبکه‌ای A*، رودخانه غیرقابل عبور و پل روی جاده

- [ ] اجرای پروژه در Godot، تست بالانس و خروجی/تست Android

### فاز ۲ — پایگاه و اقتصاد

### فاز ۳ — نقشه جهان
- نقشه سیاسی جهان
- کشورها، استان‌ها و شهرها
- مدیریت منابع ملی و دیپلماسی
- تبدیل نبرد منطقه‌ای به میدان عملیاتی مستقل

### فاز ۴ — چندنفره محلی
- اتاق LAN
- کشف میزبان یا اتصال با IP محلی
- همگام‌سازی فرمان‌ها
- تست قطع و وصل Wi-Fi و هات‌اسپات

### فاز ۵ — چندنفره آنلاین
- سرور authoritative
- لابی و دعوت دوستان
- حساب و پروفایل
- بازی رتبه‌بندی‌شده در صورت نیاز

### فاز ۶ — محتوای کامل
- کشورهای بیشتر و سناریوهای تاریخی/مدرن
- نیروهای هوایی و دریایی
- فناوری، دیپلماسی و هوش مصنوعی پیشرفته
- صدا، موسیقی، انیمیشن و بهینه‌سازی
- تست گسترده و انتشار

**اصل برنامه:** هر فاز باید یک خروجی قابل اجرا و قابل آزمایش داشته باشد. هیچ فاز بعدی نباید صرفاً بر اساس وعده یا سند، تکمیل‌شده اعلام شود.
