# نقشه راه توسعه
## Empire of Lion and Sun

### فاز ۰ — پایه پروژه
- ساختار Godot 4 و کنترل نسخه
- تنظیم نمایش افقی و ورودی لمسی
- صحنه اصلی و رابط آزمایشی

### فاز ۱ — MVP 0.1: هسته نبرد RTS
- [x] میدان نبرد ایزومتریک بزرگ با رودخانه و جاده
- [x] انتخاب تکی و گروهی و دوربین چندلمسی پایه
- [x] حرکت گروهی با آرایش ساده و فاصله‌گذاری اولیه
- [x] پیاده‌نظام، تانک و نفربر با شکل‌های متمایز
- [x] مبارزه، جان واحدها و شرط برد و باخت
- [x] منابع ساده، استخدام مستقیم نیرو و AI پایه
- [x] HUD موبایل اولیه
- [x] مسیر‌یابی شبکه‌ای A*، رودخانه غیرقابل عبور و پل روی جاده
- [x] ذخیره و بارگذاری محلی بازی
- [ ] اجرای پروژه در Godot، تست بالانس و خروجی/تست Android (اعتبارسنجی اجرایی هنوز تأیید نشده)

### فاز ۲ — پایگاه و اقتصاد
- [x] ساختمان‌های قابل ساخت: پادگان، کارخانه زرهی و انبار
- [x] زمان ساخت و محدودیت محل قرارگیری ساختمان‌ها
- [x] صف تولید واحدها با سقف صف و وابستگی به ساختمان تولیدکننده
- [x] هزینه اعتبار، سوخت و مواد اولیه برای تولید
- [x] ظرفیت منابع و افزایش ظرفیت با ساخت انبار
- [x] تعمیر و ارتقای ساختمان‌ها
- [x] ذخیره/بارگذاری نسخه‌دار ساختمان‌ها، صف‌ها و وضعیت نبرد

**وضعیت فاز ۲:** قابلیت‌ها در سورس پیاده‌سازی شده‌اند؛ تکمیل قطعی فاز ۱ و ۲ منوط به اجرای موفق تست خودکار Godot و تست دستی در بازی است. تا آن زمان این فازها «پیاده‌سازی‌شده، در انتظار اعتبارسنجی» محسوب می‌شوند.

### فاز ۳ — نقشه جهان
- نقشه سیاسی جهان
- کشورها، استان‌ها و شهرها
- مدیریت منابع ملی و دیپلماسی
- تبدیل نبرد منطقه‌ای به میدان عملیاتی مستقل

### فاز ۴ — چندنفره محلی
- اتاق LAN
- کشف میزبان یا اتصال با IP محلی
- همگام‌سازی فرمان‌ها
- تست قطع و وصل Wi-Fi و هات‌اسپات

### فاز ۵ — چندنفره آنلاین
- سرور authoritative
- لابی و دعوت دوستان
- حساب و پروفایل
- بازی رتبه‌بندی‌شده در صورت نیاز

### فاز ۶ — محتوای کامل
- کشورهای بیشتر و سناریوهای تاریخی/مدرن
- نیروهای هوایی و دریایی
- فناوری، دیپلماسی و هوش مصنوعی پیشرفته
- صدا، موسیقی، انیمیشن و بهینه‌سازی
- تست گسترده و انتشار

**اصل برنامه:** هر فاز باید یک خروجی قابل اجرا و قابل آزمایش داشته باشد. هیچ فاز بعدی نباید صرفاً بر اساس وعده یا سند، تکمیل‌شده اعلام شود.
